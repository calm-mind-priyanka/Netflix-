# StreamBox

Standalone StreamBox website connected **read-only** to the existing Telegram Auto Filter Bot MongoDB media collections.

## Architecture

`Auto Filter Bot -> existing MongoDB (read-only) -> StreamBox -> browser`

The website does not edit, migrate, clone, delete, or re-index the bot's media records.

### Existing database

The default values expected from the original bot are:

- Database: `Cluster0`
- Collection: `Sandy_files`
- Multiple DB: `True`
- Primary: `DATABASE_URI`
- Secondary: `DATABASE_URI2`

Set these through Koyeb environment variables. Never put real credentials in this project.

The website understands the Auto Filter Bot's canonical `_id` generated by its `encode_file_id()` implementation and uses the stored `file_ref` when reconstructing Telegram media locations.

## Deployment

The Docker image uses Python 3.11 and starts:

`python -m backend.app`

The server binds to `0.0.0.0:$PORT`.

Required production environment variables:

- `DATABASE_URI`
- `DATABASE_URI2` when `MULTIPLE_DB=True`
- `SITE_SECRET`
- `BOT_TOKEN`
- `API_ID`
- `API_HASH`
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD` (or `ADMIN_PASSWORD_HASH`)

Optional:

- `TMDB_API_KEY`
- `PUBLIC_URL`
- `MOVIE_SITE_SESSION`
- `CATALOG_TTL`
- `CATALOG_MAX_DOCS`
- `STREAM_TOKEN_TTL`

The application reads environment variables directly at runtime; it does not assume Koyeb loads `.env.example`.

## Admin

Open `/admin` and sign in with the Koyeb `ADMIN_USERNAME` and `ADMIN_PASSWORD`.

The admin panel can view catalog counts, refresh the in-memory catalog/metadata cache, and enable temporary in-memory maintenance mode.

Maintenance mode is intentionally **not stored in MongoDB**, so the website never creates or modifies a collection in the Auto Filter Bot database.

## Diagnostics

`/api/diagnostics` is admin-protected. It reports only whether sensitive environment variables are `SET` or `NOT SET`, plus safe database counts and Telegram client status. It never returns credential values.

## Catalog and search

The catalog reads a bounded number of recent, small-projection MongoDB documents so the website does not load large documents unnecessarily. Search queries the existing collections directly and supports case-insensitive partial token matching across `file_name` and `caption`.

The parser derives title, year, quality, language, season and episode from the actual filename/caption. It does not assume those fields exist in MongoDB.

## Streaming

The player uses short-lived signed tokens. The browser never receives Telegram credentials. Telegram media references are resolved server-side and streamed using HTTP range requests.

If Telegram credentials are unavailable, the website can still start and serve the catalog, while playback/download endpoints return a clear service-unavailable error.

## Important

The original Auto Filter Bot ZIP is not part of this project and is not modified by the StreamBox build.
